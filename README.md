SQL practice, database queries, and SQLite exercises.

### 04 — API
A book management API built with FastAPI and SQLite.

**Implemented features:**
- GET, POST, PUT, and DELETE endpoints for books
- Retrieve all books and search by ID or title
- SQLite database integration using Python's `sqlite3` module
- Separate files for API endpoints, database operations, and Pydantic models
- Basic error handling with HTTP 404 responses
- Automatic creation and updating of timestamps
- Request and response schemas for API data validation
